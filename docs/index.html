A runtime catalog for field-trades shops — not a public Softwares suite.

trades-runtime is a private documentation and operations catalog for HVAC, plumbing, electrical, sewer, and jobs that span those trades. It is a sibling product to aziel-runtime, written for trades businesses. It is not a FragGate engine dump, and v0 has no live Worker backends.

What this is

Private ops surface. This repo and site stay private. Collaborators with access can read the catalog, trade pages, and runtime.json.

  • Product name: trades-runtime
  • Version: 0.1.0
  • Role: trades-runtime
  • Author / identity: Aziel Eliab only

What v0 is not. No invented production APIs. No DOIs. No hosted Worker that executes dispatch or billing.

  • Not a public Softwares suite clone
  • Not a fork dump of aziel-runtime engines
  • Planned ops are stubs until a later version

Planned runtime ops

Every trade module will eventually expose the same five ops. In v0 they are documented only.

OpStatusIntent
dispatchplannedAssign a job to a crew with trade, window, and site notes.
estimateplannedWrite scope, materials, labor, and price before work starts.
work-orderplannedHold findings, parts, photos, and customer authorization.
inspectionplannedPre-work and post-work checks with photo evidence.
closeoutplannedSign-off, invoice, warranty, and follow-up.
