 Correction
 Wrong next-act in TR-BOT §9: “we” pull a read-only ServiceTitan dump and feed the runtime. That makes the authoring node
 a data custodian. That is not the product.
 Right model: every user (company / branch operator running trades-runtime locally) incorporates their own ServiceTitan data
 and their own ProBooks data into their runtime. The software provides the admit path, the packet shape, the hash, the
 quarantine, and the refuse-write. It does not phone home a tenant dump. It does not hold a central ST or ProBooks corpus.

 Law
    Law                                      Meaning

    FragGate still admits                    ST export, ST API read, ProBooks export, ProBooks API read — all untrusted until admitted + hashed.

    Pages / mesh                             No tenant data on GitHub Pages, Workers, or a shared demo.
