 What changed
 0.4.12 adds familiar commands on the local CLI so a person or an agent can discover the product
 without reading the whole README.

    help            Prints the command list. Same text as running the CLI with no command.
                    Aliases: --help, -h.
    softwares       Lists Softwares modules from the runtime manifest in plain language:
                    slug, status, and one line. Not a raw JSON dump.
                    Alias: Softwares (any letter case on that command word).
    version         Prints the product name and the version from the runtime manifest,
                    plus one short honesty line: live_backends false, pilot_started false.
                    Aliases: --version, -V.
    health          Same local honesty card as health-local. health-local still works.

 Existing commands stay: manifest, demo, byo-admit-demo, drop-in-demo, shadow-sealed-demo,
 health-local, pilot-prep, desk.
