 What a shop does
    1. Clone this repo on the shop machine. npm install. npm test.
    2. npm run pilot:prep. The receipt keeps pilot_started false.
    3. Place that shop's own exports under data/inbound/servicetitan, data/inbound/probooks, or data/inbound/trades-app when they choose to. Empty stays empty. Do not commit a customer file.
    4. Credentials stay in environment variables on that machine. write-backends.json names those variables and does not hold a token.
    5. npm run pilot:start -- --branch <branchId>
    6. npm run desk on 127.0.0.1:4174. That desk is the shop's office. It is not served by the public Worker.
